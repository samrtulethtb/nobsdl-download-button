NoBsDL Video Downloader userscript

A free, open-source userscript that puts a Download button on video pages. Pick a real quality with its file size, as MP4 video or MP3 audio, and the file goes straight to your browser's downloads: no new tab, no copied links, no third-party converter sites. Version 2.2.1, MIT licensed.

Install from Greasy Fork Source on GitHub Use NoBsDL without the script

What it does

  • Real qualities, real sizes. Every choice comes from the actual source (for example 720p60 · ~173 MB, or MP3 320 kbps), listed by NoBsDL. Nothing is invented.
  • Live progress. Queue → Download → Process → Ready, with a real percentage, speed and time left measured on the server.
  • MP4 and MP3. Video qualities next to MP3 at 128, 256 and 320 kbps.
  • Works while you scroll. On TikTok's For You feed, X timelines and Bluesky the button takes the clip on screen, without opening each video first.
  • Made for phones too. A round button you can drag anywhere and a bottom sheet with big touch targets.
  • Stays out of the way. Close the panel mid-download and it keeps going; the button shows the percentage.

Install

  1. Install Tampermonkey or Violentmonkey.
  2. Open the script on Greasy Fork and press Install. Updates arrive automatically.

Privacy

The script talks only to nobsdl.com, and only after you click. It contains no analytics, ads or tracking code, and stores only whether you minimized the button and where you dragged it. The code is readable and unminified.

Most downloads are free; some higher resolutions and files over the free size limits (500 MB video, 100 MB MP3) need a paid NoBsDL Supporter key. Download only media you are allowed to save. · nobsdl.com · GitLab mirror
